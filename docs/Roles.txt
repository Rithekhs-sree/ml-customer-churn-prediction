============================================================

1. PROJECT OVERVIEW
   ============================================================

This is a two-member group assignment for the Fundamentals of Machine Learning module.

The project will address a real-world telecommunications problem: customer churn prediction.

Customer churn refers to a customer ending their relationship with a telecommunications service provider.

The purpose of this project is to investigate whether machine learning algorithms can use existing customer information to predict whether a customer is likely to churn.

The project will use supervised machine learning and binary classification.

Two different non-deep-learning machine learning algorithms will be implemented and compared:

1. Logistic Regression
2. Random Forest Classifier

The performance of the two algorithms will be evaluated using appropriate classification metrics and discussed in relation to the customer churn problem.

The assignment requires two distinct algorithms for a group of two students when supervised learning is selected.

Reference to assignment requirement: The assignment allows a real-world problem using a real-world dataset and requires two distinct supervised-learning algorithms for a two-member group.



============================================================
2. PROBLEM STATEMENT
====================

Telecommunications companies lose customers when customers cancel their services or move to another provider. Identifying customers who are likely to leave can help a company take appropriate customer-retention actions.

The problem addressed in this project is: "Can machine learning algorithms accurately predict whether a telecommunications customer is likely to churn based on their demographic information, service information, contract details, and billing characteristics?"

The target variable will represent whether the customer churned or did not churn.

The project will investigate which of the two selected machine learning algorithms performs better for predicting customer churn.



============================================================
3. ML APPROACH
==============

Machine Learning Type: Supervised Learning

Machine Learning Task: Binary Classification

Target: Customer Churn

Target Classes:

* Churn
* No Churn

Algorithms:

Algorithm 1: Logistic Regression

Purpose: To provide an interpretable classification model that estimates the likelihood of a customer belonging to the churn class.

Algorithm 2: Random Forest Classifier

Purpose:To provide a tree-based ensemble classification model capable of capturing non-linear relationships and interactions between features.

The two algorithms will be trained and tested using the same prepared dataset so that their performance can be fairly compared.

Deep Learning will NOT be used because the assignment explicitly states that only Machine Learning and non-Deep Learning algorithms/models may be used.
